Comprehensive Capability Matrix

KAMAuto Feature Arsenal

Discover every granular tool built into dist\KAMauto.exe to handle clicks, macros, scripts, and profiles seamlessly.

🖱️

Clicking Controls

  • • Start and stop a real autoclicker from buttons or anywhere using global F1 and F2 hotkeys.
  • • Set click intervals down to a fraction of a millisecond.
  • • Target the current spot, one chosen point, or a custom path of several points.
  • • Single or double click with left, right, or middle mouse buttons.
  • • Repeat a set count, hold button down, or toggle run states.
  • • Add random delays and pixel jitter to avoid mechanical patterns.
⌨️

Keyboard Automation

  • • Pick any key from an on-screen keyboard: letters, numbers, function keys, punctuation, modifiers, arrows, and numpad.
  • • Type freeform shortcuts in a text field, such as f6 or ctrl+shift+k.
  • • Tap a key, hold it down, or expand a text snippet on a hotkey.
  • • Modifiers automatically release when a run stops, preventing stuck Ctrl keys.
🔴

Recording & Playback

  • • Record mouse moves, clicks, scroll wheel, and keys simultaneously.
  • • Automatically drop tiny, erratic mouse tremors before playback for clean macros.
  • • Adjust playback speed easily: 2x speed is twice as fast, 0.5 speed runs at half pace.
📜

Advanced Scripts

  • • Build a step list you can add to, edit, and reorder without recording again.
  • • Utilize if/else, loops, variables, try/catch, and clipboard integration.
  • • Set breakpoints and step through one line at a time.
  • • Safety feature: each wait times out and gives up after 5 seconds instead of freezing your computer.
  • • Pause a script dynamically until a chosen pixel on screen matches a target color.
💾

Profiles, Security & Sharing

  • • Save separate profiles directly on disk.
  • • Lock any macro file with a password.
  • • Maintain a local audit log of each run in kamauto.log.
  • • Share a single executable: dist\KAMauto.exe. Profiles and logs are automatically created next to it.
